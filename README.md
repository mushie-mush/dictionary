# React + TypeScript + Vite Dictionary App

This project is a simple dictionary application built using React, TypeScript, and Vite. It allows users to search for word definitions and save words to a personal collection.

## Features

- **Word Search:** Look up definitions for various words.
- **Saved Words:** Save words to a personal collection for later review.
- **Progressive Web App (PWA):** Installable and works offline.

## Technologies Used

- [React](https://reactjs.org/): A JavaScript library for building user interfaces.
- [TypeScript](https://www.typescriptlang.org/): A typed superset of JavaScript.
- [Vite](https://vitejs.dev/): A fast build tool and development server.
- [Tailwind CSS](https://tailwindcss.com/): A utility-first CSS framework.
- [React Router](https://reactrouter.com/): A standard library for routing in React.
- [Vite PWA](https://vite-pwa-org.netlify.app/): Zero config PWA Plugin for Vite

## Setup

1.  **Clone the repository:**

    ```bash
    git clone <repository-url>
    ```

2.  **Install dependencies:**

    ```bash
    npm install
    ```

3.  **Start the development server:**

    ```bash
    npm run dev
    ```

4.  **Open the app in your browser:** Navigate to `http://localhost:5173` (or the URL provided by Vite).
